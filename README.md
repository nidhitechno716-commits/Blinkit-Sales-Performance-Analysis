# Blinkit Sales & Performance Analysis

## 📊 Project Overview

This project focuses on analyzing Blinkit sales data to understand overall sales performance, outlet performance, product-level performance, and key business trends.

The project follows an end-to-end data analytics workflow:

**Data Cleaning → SQL Analysis → Power BI Dashboard → Business Insights**

---

## 🎯 Business Objective

The objective of this project is to analyze Blinkit's sales data and answer important business questions related to:

- Sales performance
- Outlet performance
- Product performance
- Outlet location
- Outlet size
- Outlet type
- Item characteristics
- Customer ratings

The analysis is presented through an interactive Power BI dashboard.

---

## 📁 Dataset

The dataset contains information related to Blinkit outlets and items, including:

- Item Type
- Fat Content
- Item Weight
- Item Visibility
- Item MRP
- Sales
- Rating
- Outlet Type
- Outlet Size
- Outlet Location Type
- Outlet Establishment Year

---

## 🧹 Data Cleaning

The dataset was prepared before performing the analysis.

The data preparation process included:

- Checking missing values
- Checking duplicate records
- Correcting data types
- Standardizing categorical values
- Preparing fields for analysis
- Creating required calculated fields

**Tools used:** Excel, Power Query and SQL

---

## 🗄️ SQL Analysis

SQL was used to perform business-oriented analysis on the dataset.

The analysis includes:

- Total sales
- Average sales
- Number of items
- Average rating
- Sales by outlet type
- Sales by outlet location
- Sales by item type
- Sales by fat content
- Outlet performance
- Outlet establishment trends

The SQL queries used for the analysis are available in:
